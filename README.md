# PersonalCodingMoat

Shared coding principles for agents working on my projects.

Before starting work, read and follow [AGENTS.md](AGENTS.md).

## Codex

Place or merge this repository's [AGENTS.md](AGENTS.md) into `AGENTS.md` at the root of your working repository. Codex loads it automatically unless an `AGENTS.override.md` takes precedence in that directory. [Official documentation](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

## Claude Code

Copy or merge the contents of this repository's [AGENTS.md](AGENTS.md) into `CLAUDE.md` at the root of your working repository. Claude Code loads `CLAUDE.md` automatically. [Official documentation](https://code.claude.com/docs/en/memory).

For either harness, preserve existing project-specific instructions when merging. Start a new session in the working repository after setup.
